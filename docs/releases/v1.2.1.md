# DnsForward v1.2.1

> 本版本主要补齐 Linux 版本检查、手动升级、可选自动升级和失败回滚能力。

### ✨ 主要更新

- **版本检查**
  - 新增 `dnsforwardctl check-update`，显示当前版本与 GitHub 最新正式 Release。
  - 已是最新版时明确提示，无需重复替换二进制。

- **手动升级**
  - 新增 `dnsforwardctl upgrade`，默认升级到最新正式版本。
  - 支持 `dnsforwardctl upgrade vX.Y.Z` 指定版本。
  - 自动识别 Linux amd64 / arm64，并下载对应 Release 包。

- **可选自动升级**
  - 新增 `dnsforwardctl auto-update enable|disable|status`。
  - 自动升级默认关闭，必须显式启用。
  - 启用后由 systemd timer 每日检查并升级到 GitHub 最新正式 Release。
  - timer 使用 `Persistent=true`，并增加最多 1 小时随机延迟，避免所有实例同时访问 GitHub。

- **失败自动回滚**
  - 升级前备份当前可执行文件。
  - 新版本替换后重启 `dnsforward.service` 并检查服务状态。
  - 如果新版本无法保持 active，会自动恢复旧二进制并重新启动服务。

### 🔒 安全与稳定性

- 下载 Release 后必须通过 `checksums.txt` 的 SHA256 校验才会继续安装。
- 同时验证包内 `dnsforward -v` 输出与目标版本一致，避免错误资产被替换到生产二进制。
- 升级过程不会覆盖 `/etc/dnsforward/config.yaml`。
- 自动升级只跟随 GitHub `latest` 正式 Release，不使用 prerelease。
- 升级时会同步刷新 `/usr/local/bin/dnsforwardctl`，确保管理脚本与当前版本能力一致。
- 卸载 DnsForward 时会同时移除自动升级的 systemd timer/service。
- 完整 CI 已通过安装脚本语法检查、test、race、staticcheck、govulncheck 和六平台构建。

### 📦 升级说明

v1.2.0 用户升级到 v1.2.1 后即可使用新的更新命令：

```bash
dnsforwardctl check-update
sudo dnsforwardctl upgrade
```

开启自动升级：

```bash
sudo dnsforwardctl auto-update enable
```

查看状态：

```bash
sudo dnsforwardctl auto-update status
```

关闭自动升级：

```bash
sudo dnsforwardctl auto-update disable
```

自动升级默认不会开启；如果你更倾向手工控制版本，只使用 `check-update` 和 `upgrade` 即可。

### ✅ 兼容性

- Linux amd64 / arm64：支持安装、升级、回滚和 systemd 自动升级。
- macOS amd64 / arm64：继续提供 Release 构建，但本次 Linux 管理脚本功能不适用。
- Windows amd64 / arm64：继续提供 Release 构建，但本次 Linux 管理脚本功能不适用。
